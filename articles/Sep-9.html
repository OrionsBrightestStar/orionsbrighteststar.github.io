2. Sard's Theorem and Regular Values

We begin with the notion of a critical point, which is a generalization of the concept of a critical point from single-variable calculus. The image of such is called a critical value, and any point that is not a critical value is considered regular.

Definition 1 (Critical Point/Value)

Suppose $\phi: M^m \to N^n$ is a smooth map. We say a point $p \in M^m$ is a critical point of $\phi$ if $\phi_*: T_p(M) \to T_{\phi(p)}(N)$ has rank less than $n$. The image of a critical point in $N^n$ is called a critical value. Any point in $N^n$ that is not a critical value is called a regular value, even if it is not in the image of $\phi$.

We now approach one of the main results regarding regular values, the proof of which requires some measure theory, and so will not be provided here. The interested reader is directed to Appendix C of Bredon's Topology and Geometry for further information.

Theorem 1 (Sard's Theorem)

If $\phi: M^m \to \mathbb{R}^n$ is a smooth map, then the set of critical values has measure zero; that is, we can cover the set of critical values with a countable number of intervals of arbitrarily small length.

A corollary swiftly follows from Sard's Theorem.

Corollary 1 (A.B. Brown)

Suppose that $\phi: M^m \to N^n$ is smooth. Then the set of regular values is residual in $N^n$.

Proof.

Suppose $C$ is the critical set of $\phi$ (that is, the set of critical points), and $K \subset M$ is a compact set. It naturally follows that $\phi(C \cap K)$ is compact and has empty interior, due to Sard's Theorem. It naturally follows from elementary properties in real analysis that $\phi(C \cap K)$ is nowhere dense in the codomain $N$. $M$ may be covered by a countable number of such compact $K$, so $\phi(C)$ is of first category (that is, it can be covered by a countable number of nowhere dense sets), and so its complement is residual (I still have no idea what residual means).

Interestingly enough, Sard's theorem can be used to prove the Fundamental Theorem of Algebra. We shall do so now, with an argument straight from Milnor's Topology from the Differentiable Viewpoint.

Corollary 2 (Fundamental Theorem of Algebra)

Suppose $p(z)$ is a complex polynomial, with degree not zero. Then $p(z)$ has a zero.

Proof.

Suppose $p(x+iy) = u(x,y)+iv(x,y)$. Differentiating, we get $p'(z)=(u_x+iv_x)=-i(u_y+iv_y)$, as we may be able to differentiate the expression with respect to $x$ and $y$ and equate the two. It follows that the Jacobian $J(u,v;x,y) = u_x^2 + u_y^2$ is zero if and only if $p'(z)=0$. It follows that there are only a finite number of points (which are zeros of $p'$) that can satisfy this, so $p: \mathbb{R}^2 \to \mathbb{R}^2$ has only a finite number of critical points, the set of which we shall denote by $F$. Now, suppose $p(z) = a_0 z^n + a_1 z^{n-1}+ \cdots + a_n$ such that $a_0 \not = 0$. We have that $$ |p(z)| = |z|^n |a_0 + a_1 z^{-1}+\cdots + a_n z^{-n}|$$ shows that as $|z| \to \infty$, then $|p(z)| \to \infty$. So, we may extend $p$ continuously to the one-point compactification $S^2$ of $\mathbb{R}^2$. This allows each compact subset of $S^2$ to have a compact image, and so $p$ is by definition a proper map. It is an earlier result from the textbook that it follows that $p$ is a closed mapping. Now, we have that $p^{-1}(c)$ consists of the zeros of the polynomial $p(z)-c$, and so may contain at most $n$ points (I guess it is a result we may use that a polynomial has at most its degree in terms of roots). Suppose $k = k(c)$ be the number of points in $p^{-1}(c)$. Then, if $c$ is regular and $p^{-1}(c) = \{z_1,\ldots, z_k\}$, then we may say that each $z_i$ has a neighborhood $U_i$ which is diffeomorphic to a neighborhood $V_i \subset \mathbb{R}^2 - F$ of $c$. Note that $\mathbb{R}^2$ is Hausdorff, so let $U_i$ be disjoint. Consider that there exists an open connected neighborhood $V$ of $c$ inside the very complicated looking open set $V_1 \cap \cdots \cap V_k - f(\mathbb{R}^2 - (U_1 \cup \cdots \cup U_k))$. Let $W_i = U_i \cap p^{-1}(V)$. This is diffeomorphic by $p$ onto $V$. We also have that $p^{-1}(V) = W_1 \cup \cdots \cup W_k$, which are each disjoint. Therefore, $k(c)$ is locally constant on $\mathbb{R}^2 - F$, but $\mathbb{R}^2 - F$ is connected, so $k(c)$ is constant on $\mathbb{R}^2 - F$.
